# 2025 APMCM Problem C · 问题一建模思路

> **题目重述**：美国、巴西、阿根廷是世界最大的大豆生产国与出口国，中国是最大的大豆进口国。
> 要求：① 分析中国与美/巴/阿大豆贸易现状；② 建立模型评估美国关税调整对三国大豆产业的影响；
> ③ 估算调整后三国大豆**出口量**与**出口额**的分布。
>
> **核心建模逻辑**：用"局部均衡 + Armington 来源替代"求解三国出口分布（主模型），用"结构引力模型"做参数校准与交叉检验，用"2018 年中美贸易战"做历史反事实验证；可选 GTAP/CGE 做一般均衡扩展。

---

## 1. 系统边界与假设

- **主体**：中国（唯一进口方，需求侧）；供应方 $i\in\{\text{US},\text{BR},\text{AR},\text{ROW}\}$（美、巴、阿 + 其他国家作为剩余供应）。
- **商品**：大豆（HS 1201），视为同质可贸易品，但来源国之间存在**有限替代**（Armington 假设）。
- **冲击渠道**：题目"美国关税调整"→ 贸易摩擦 → **中国对美大豆加征反制关税**（如 2018 年 +25%），对应模型中的 $t_{\text{US}}\uparrow$。
- **短期假设**：中国大豆总消费需求由收入与价格决定；弹性在短期内固定；汇率、其他部门联动放到 CGE 扩展中。

| 层 | 模型 | 作用 |
|---|---|---|

## 3. 核心模型：局部均衡 + Armington 替代

### 3.1 符号表

| 符号 | 含义 |
|---|---|
| $Q$ | 中国大豆总进口量（复合指数） |
| $q_i$ | 自来源 $i$ 的进口量 |
| $p_i$ | 中国自 $i$ 进口价（含关税 CIF） |
| $p_i^*$ | 来源 $i$ 净出口价（FOB，不含关税） |
| $t_i$ | 对来源 $i$ 从价关税率 |
| $P$ | 复合进口品 CES 价格指数 |
| $\sigma$ | Armington 来源替代弹性（$\sigma>1$） |
| $\eta$ | 中国进口需求价格弹性（$\eta<0$） |
| $\beta$ | 进口需求收入弹性（$\beta>0$） |
| $\varepsilon_i$ | 来源 $i$ 出口供给弹性（$\varepsilon_i>0$） |
| $c_i$ | 来源 $i$ 的**支出份额**（$\sum_i c_i=1$） |

### 3.2 需求侧：Armington CES 聚合（含推导）

中国将各来源大豆组合成复合进口品：
$$Q=\left(\sum_i a_i\,q_i^{\frac{\sigma-1}{\sigma}}\right)^{\frac{\sigma}{\sigma-1}},\qquad \sigma>1$$

成本最小化 $\min\sum_i p_i q_i\;\text{s.t.}\;Q$ 给定，由一阶条件导出：

- **价格指数**
  $$P=\left(\sum_i a_i^{\sigma}\,p_i^{\,1-\sigma}\right)^{\frac{1}{1-\sigma}}$$
- **各来源进口量**
  $$q_i=a_i^{\sigma}\left(\frac{P}{p_i}\right)^{\sigma}Q$$
- **支出份额**（这是真正加总到 1 的份额）
  $$c_i\equiv\frac{p_i q_i}{PQ}=a_i^{\sigma}\left(\frac{p_i}{P}\right)^{1-\sigma},\qquad \sum_i c_i=1$$

> **说明**：CES 下数量份额 $q_i/Q$ **不**等于 1（$Q$ 是指数）；算"出口额"用 $c_i$ 或 $p_i q_i$，算"出口量"用 $q_i$。
> 基年参数校准：$a_i=(c_i^0)^{1/\sigma}(p_i^0)^{(\sigma-1)/\sigma}$（取 $P^0=1$）。

### 3.3 中国总进口需求

$$Q^d=A\cdot P^{\eta}\cdot Y^{\beta}$$

- $\eta<0$（价格弹性，大豆压榨/饲用需求较缺乏弹性，经验约 $-0.3\sim-0.8$）；
- $\beta>0$（收入弹性，约 $0.8\sim1.2$）；
- 短期可令 $Y$ 不变，则 $\Delta\ln Q=\eta\,\Delta\ln P$；
- $\eta,\beta$ 可用 2020–2025 历史序列对数回归估计。

### 3.4 供给侧：来源国出口供给

出口商关心实际拿到的净价 $p_i^*$：
$$q_i^s=B_i\,(p_i^*)^{\varepsilon_i}$$

- $\varepsilon_i$ 由可调产能/可重定向能力决定：巴西、阿根廷耕地扩展空间大 → $\varepsilon$ 较高（约 2~3）；美国短期受限 → 略低（约 1~2）；
- 估计：$\ln q_{it}=\ln B_i+\varepsilon_i\ln p_{it}^*+u_{it}$，或取 GTAP / Berthou et al. (2024) 经验值。
- 关税楔子：$p_i=p_i^*(1+t_i)$。**关税归宿（pass-through）**由相对弹性内生决定——谁承担关税在 3.5 节解出。

### 3.5 市场均衡与对数线性闭式解

令 $q_i^d=q_i^s$，对全部方程取对数差分（$\Delta x\equiv\Delta\ln x$）：

$$
\begin{aligned}
&\text{(需求)}\quad \Delta q_i=\sigma(\Delta P-\Delta p_i)+\Delta Q \tag{1}\\
&\text{(供给)}\quad \Delta q_i=\varepsilon_i\,\Delta p_i^* \tag{2}\\
&\text{(楔子)}\quad \Delta p_i=\Delta p_i^*+\Delta\ln(1+t_i) \tag{3}\\
&\text{(总需求)}\quad \Delta Q=\eta\,\Delta P+\beta\,\Delta Y \tag{4}\\
&\text{(价格指数)}\quad \Delta P=\sum_i c_i^0\,\Delta p_i \tag{5}
\end{aligned}
$$

**价格指数线性化推导**：由 $P=(\sum_i a_i^\sigma p_i^{1-\sigma})^{1/(1-\sigma)}$ 微分得
$$\frac{\partial\ln P}{\partial\ln p_k}=\frac{a_k^\sigma p_k^{1-\sigma}}{\sum_j a_j^\sigma p_j^{1-\sigma}}=c_k\quad\Rightarrow\quad\Delta P=\sum_i c_i^0\,\Delta p_i$$

**闭式求解**：由 (1)(2)(3) 消元得各来源含关税价
$$\Delta p_i=\frac{\sigma\,\Delta P+\Delta Q+\varepsilon_i\,\Delta\ln(1+t_i)}{\sigma+\varepsilon_i}\tag{*}$$

短期 $\Delta Y=0\Rightarrow\Delta Q=\eta\Delta P$，代入 (5)：
$$\Delta P=\sum_i c_i^0\,\frac{(\sigma+\eta)\Delta P+\varepsilon_i\,\Delta\ln(1+t_i)}{\sigma+\varepsilon_i}$$
这是关于 $\Delta P$ 的一元一次方程，解出 $\Delta P\to\Delta Q\to\Delta p_i\to\Delta p_i^*\to\Delta q_i$。

**最终输出**：
$$q_i^{\text{new}}=q_i^0 e^{\Delta q_i},\qquad V_i^{\text{FOB}}=p_i^{*,new}\,q_i^{\text{new}},\qquad \tilde s_i=\frac{q_i^{\text{new}}}{\sum_j q_j^{\text{new}}}$$

**数值示例（美、巴两源，示意）**：取 $c_{\text{US}}^0=0.4,c_{\text{BR}}^0=0.6,\sigma=3,\eta=-0.5,\varepsilon_{\text{US}}=1.5,\varepsilon_{\text{BR}}=2.5$，美国关税 0→30%（$\Delta\ln(1+t)=0.262$）。解得：

| 变量 | 结果 |
|---|---|
| 总体进口价指数 $P$ | +6.9% |
| 总体进口量 $Q$ | −3.5% |
| 美国含关税价 $p_{\text{US}}$ | +12.6% |
| 巴西含关税价 $p_{\text{BR}}$ | +3.1% |
| 美国净价 $p_{\text{US}}^*$ | **−13.6%** |
| 巴西净价 $p_{\text{BR}}^*$ | **+3.1%** |
| 美国出口量 $q_{\text{US}}$ | **−20.4%** |
| 巴西出口量 $q_{\text{BR}}$ | **+7.9%** |

读图：美豆量与净价双降（丢市场+被压价），巴西量与净价双升（承接转移+获定价权）；30% 关税中约 13.6% 由美出口商吸收、约 12.6% 转嫁中国买家——即关税归宿。

## 4. 参数校准与交叉检验（结构引力模型）

### 4.1 数据与样本
- 双边大豆流量 $Trade_{ijt}$（中国←美/巴/阿/ROW），HS 1201，2016–2025：UN COMTRADE、USITC DataWeb、中国海关；
- 双边 GDP（World Bank）、地理距离 $Dist_{ij}$、双边从价税率 $Tariff_{ijt}$（WTO / USTR / 商务部公告）。

### 4.2 设定（PPML 结构引力）
$$Trade_{ijt}=\exp(\beta_0+\beta_1\ln GDP_{it}+\beta_2\ln GDP_{jt}+\beta_3\ln Dist_{ij}+\beta_4 Tariff_{ijt})\,\mu_{it}\mu_{jt}\varepsilon_{ijt}$$
- 用 **PPML** 处理零贸易流、对乘法误差稳健；
- 加入**进出口国—年固定效应** $\mu_{it},\mu_{jt}$ 吸收多边阻力，使 $\beta_4$ 干净识别关税效应。

### 4.3 弹性映射
来源 $i$ 支出份额对关税的弹性近似
$$\frac{\partial\ln c_i}{\partial\ln(1+t_i)}\approx(1-\sigma)\frac{t_i^0}{1+t_i^0}$$
令其等于引力估计 $\hat\beta_4$，反解 Armington 替代弹性：
$$\hat\sigma=1-\frac{\hat\beta_4(1+t_i^0)}{t_i^0}$$

### 4.4 三个落地层次

- **A. 参数校准（内部）**：用引力估计 $\beta_4,\eta,\varepsilon_i$，翻译为 $\sigma,\eta,\varepsilon_i$ 喂给核心模型（2.5 闭式）。
- **B. 交叉检验（模型 vs 模型）**：直接把关税情景代入引力模型预测三国出口额/份额，与核心模型输出比较，相对偏差 $\text{Dev}_i=|\tilde s_i^{\text{core}}-\tilde s_i^{\text{grav}}|/\tilde s_i^{\text{grav}}$；若各源 $<10\%\sim15\%$ 视为一致，偏差大则回溯重估 $\sigma$。
- **C. 历史反事实验证（模型 vs 现实，最关键）**：把校准好的核心模型套 2018 年（中国对美豆 +25%），用以下方法对比真实变动：
  - **双重差分/事件研究**：处理组=美→中大豆出口，对照组=美→他国或巴→中出口；
    $$\ln Export_{kt}=\alpha+\beta(Post_t\times Treat_k)+\gamma Post_t+\delta Treat_k+\varepsilon_{kt}$$
  - **合成控制法**：用未受冲击的出口—目的国组合构造反事实美→中序列，实际−反事实=关税缺口。
  - **真实参照**（公开数据量级）：美占中国进口份额 2017 ~34% → 2018 ~18%（约 −16pct），美对华出口量约 −48%，巴西对华出口量约 +32%。
  - 若核心模型预测的下降/上升幅度与真实同方向、量级接近，则判定校准通过；否则调整弹性重跑，形成"估计→求解→反事实→再估计"闭环。

## 9. 一句话总结

**核心**：用 Armington CES 把中国大豆总进口需求拆成美/巴/阿三来源，关税楔子抬升美豆价格 → 份额向巴阿转移，联立进口需求弹性与各国出口供给弹性，闭式求解新的出口量/额分布；**校准**靠 PPML 引力模型回估弹性；**验证**靠 2018 贸易战自然实验；**深化**用 GTAP/CGE 捕捉产业一般均衡效应。

## 10. 优化备注（待后续实现）

### 10.1 简化闭式解的适用范围与非线性校验

- **问题所在**：第 3.5 节用基年支出份额固定加权，写出 $\Delta\ln P\approx\sum_i c_i^0\Delta\ln p_i$。这是 CES 价格指数在基年附近的一阶近似；有限幅度的关税冲击下，各来源支出份额会变化，因此该式一般不是精确等式。其余固定弹性方程的对数变化关系在参数不变时可以精确成立，核心近似来自这里。
- **影响**：关税变化较大时，闭式解可能对价格、贸易转移及出口量额产生明显偏差。用 $e^{\Delta\ln x}$ 还原水平值，只是还原对数变化，并不能消除前面线性化的误差。
- **后续处理建议**：保留闭式解用于解释传导机制和提供数值初值；以同一组参数、基年数据和关税情景联立求解第 3.2—3.4 节的完整非线性均衡方程，核对价格、各来源数量及出口额。校准时保证完整模型能复现基年均衡；最终结果优先报告通过收敛及均衡残差检查的非线性解，并列示与闭式近似的偏差。
- **结果表述**：$\Delta\ln x$ 与普通百分比变化应区分，后者为 $100(e^{\Delta\ln x}-1)\%$；复合数量指数 $Q$ 与实际进口总吨数 $\sum_i q_i$ 也应分别报告。
- **当前状态**：仅记录优化事项，尚未编写求解代码，也未改动原有公式和流程图。

### 10.2 参数校准方法修正（已确认方向）

保留“局部均衡 + Armington CES”核心框架，后续依据可得数据修正校准方法。仅以中国为进口方的样本不能同时依赖出口国—年固定效应来识别同层级的关税变化；第 4.3 节的关税系数到替代弹性的映射也需重新推导，明确关税变量采用 $t$、$\ln t$ 还是 $\ln(1+t)$，以及被解释变量是贸易额还是支出份额。在修正之前，不直接采用现有映射公式。需求弹性和供给弹性应分别校准，不能假定一个引力关税系数能识别所有弹性。

### 10.3 题目口径与模型边界

已核对项目内题目 PDF 第 2 页问题一：题目先要求分析中国与美、巴、阿的大豆贸易，再要求估算三国调整后的出口量、出口额分布；末句没有明确限定为对华出口或全球出口。结合上下文，现有模型可按“对华出口分布”作为主分析口径，但应在论文中明确这是模型边界，而不是题目明示的全球出口口径。当前模型不能直接给出三国全球出口总量；若需覆盖全球产业及出口影响，还需补充非中国目的地的贸易重定向分析。
