下面把问题一的建模方法**完整展开**，给出可直接落地的三层模型结构、方程、校准与验证步骤。整体思路：**核心用"局部均衡 + Armington 来源替代"求解三国出口分布，用"引力模型"做参数校准/交叉验证，用"GTAP/CGE"做一般均衡扩展，最后用 2018 年中美贸易战做自然实验校准**。

---

## 一、系统边界与假设

- **主体**：中国（唯一进口方，需求侧）；供应方 \(i \in \{\text{US},\text{BR},\text{AR},\text{ROW}\}\)（美、巴、阿 + 其他国家作为剩余供应）。
- **商品**：大豆（HS 1201），视为同质可贸易品，但来源国之间存在**有限替代**（Armington 假设）。
- **冲击**：美国关税上调（或中国对美反制关税）→ 美豆到岸含关税价格上升。
- **短期假设**：中国大豆总消费需求（压榨+食用）由收入与价格决定，供给弹性和替代弹性在短期内固定；汇率、其他部门影响放到 CGE 扩展里。

## 二、核心模型：局部均衡 + Armington 替代

### 2.1 符号
| 符号              | 含义                                             |
| ----------------- | ------------------------------------------------ |
| \(Q\)             | 中国大豆总进口量                                 |
| \(q_i\)           | 自来源 \(i\) 的进口量                            |
| \(p_i\)           | 中国自 \(i\) 进口的价格（含关税 CIF）            |
| \(p_i^*\)         | 来源 \(i\) 的净出口价格（FOB，不含关税）         |
| \(t_i\)           | 对来源 \(i\) 的从价关税率                        |
| \(P\)             | 复合进口品 CES 价格指数                          |
| \(\sigma\)        | Armington 来源替代弹性（\(\sigma>1\)）           |
| \(\eta\)          | 中国进口需求价格弹性（\(\eta<0\)）               |
| \(\beta\)         | 进口需求收入弹性（\(\beta>0\)）                  |
| \(\varepsilon_i\) | 来源 \(i\) 的出口供给弹性（\(\varepsilon_i>0\)） |

### 2.2 需求侧（Armington CES 聚合）
中国将不同来源的大豆组合成复合进口品：
\[
Q=\left(\sum_i \theta_i\, q_i^{\frac{\sigma-1}{\sigma}}\right)^{\frac{\sigma}{\sigma-1}}
\]
成本最小化导出来源 \(i\) 的进口份额与数量：
\[
s_i\equiv \frac{q_i}{Q}=\theta_i\left(\frac{p_i}{P}\right)^{1-\sigma},\qquad
q_i=\theta_i\left(\frac{p_i}{P}\right)^{-\sigma}Q
\]
其中 CES 价格指数
\[
P=\left(\sum_i \theta_i\, p_i^{\,1-\sigma}\right)^{\frac{1}{1-\sigma}}
\]

### 2.3 总进口需求
\[
Q^d = A\cdot P^{\eta}\cdot Y^{\beta}
\]
（短期可令 \(Y\) 不变，则 \(\Delta\ln Q=\eta\,\Delta\ln P\)）

### 2.4 供给侧（出口供给函数）
\[
q_i^s = B_i\,(p_i^*)^{\varepsilon_i}
\]
且关税楔子：
\[
p_i = p_i^*(1+t_i)
\]

### 2.5 市场均衡与对数线性求解（实践用）
对每个来源 \(i\) 令 \(q_i^d=q_i^s\)，对方程取对数差分得到可解的线性方程组：

\[
\begin{cases}
\Delta\ln Q = \eta\,\Delta\ln P \quad (\text{短期 }Y\text{ 固定})\\[4pt]
\Delta\ln s_i = (1-\sigma)(\Delta\ln p_i-\Delta\ln P)\\[4pt]
\Delta\ln q_i = \Delta\ln s_i+\Delta\ln Q = \varepsilon_i\,\Delta\ln p_i^*\\[4pt]
\Delta\ln p_i = \Delta\ln p_i^* + \Delta\ln(1+t_i)\approx \Delta\ln p_i^* + \dfrac{\Delta t_i}{1+t_i^0}
\end{cases}
\]

未知量 \(\{\Delta\ln P,\Delta\ln Q,\Delta\ln p_i,\Delta\ln p_i^*,\Delta\ln q_i,\Delta\ln s_i\}_{i}\)，由份额约束 \(\sum_i s_i^0\Delta\ln s_i=0\) 闭合，可解析/数值求解。

**输出**：给定新的 \(t_{\text{US}}\)，解出 \(\Delta\ln q_i\) 与新的 \(p_i^*\)，则
- 三国**出口量** \(q_i^{\text{new}}=q_i^0\,e^{\Delta\ln q_i}\)
- 三国**出口额（FOB）** \(V_i=p_i^{*,new}\cdot q_i^{\text{new}}\)
- **市场份额** \(\tilde s_i=q_i^{\text{new}}/\sum_j q_j^{\text{new}}\)

直觉：美豆 \(t_{\text{US}}\uparrow \Rightarrow p_{\text{US}}\uparrow \Rightarrow s_{\text{US}}\downarrow\)；巴、阿因 Armington 替代承接转移（\(s_{\text{BR}},s_{\text{AR}}\uparrow\)），且 \(p_{\text{BR}}^*,p_{\text{AR}}^*\) 略升（获得定价权），对应 Hong & Lee (2025)、Dang et al. (2023) 的"贸易转移 + 比较优势"机制。

## 三、参数校准与交叉验证（引力模型）

用 **结构引力模型（PPML）** 从实际数据回估关键弹性，避免主观取值：

\[
\ln \text{Trade}_{ijt}= \beta_0+\beta_1\ln GDP_{it}+\beta_2\ln GDP_{jt}+\beta_3\ln Dist_{ij}
+\beta_4 Tariff_{ijt}+ \mu_{it}+\mu_{jt}+\varepsilon_{ijt}
\]
- 样本：2016–2025 年 HS6 大豆 bilateral 流量（中国←美/巴/阿/ROW）。
- \(\beta_4\) 即**关税弹性**，直接进入 Armington 的 \(\sigma\) 校准（\(\sigma\approx -1/\beta_4\) 量级关系）。
- 用 PPML（非对数 OLS）处理零贸易流；加入进出口国—年固定效应消除混淆（参考 Gan & Lee 2025、Cheong & Jang 的结构引力设定）。
- 用估计出的弹性再跑核心模型，两法互校。

弹性经验取值参考：Armington \(\sigma\) 农产品同质品约 2–4；出口供给弹性 \(\varepsilon\) 巴西/阿根廷较高（竞争型出口国），美国受关税冲击时短期偏低；取自 GTAP 参数库与 Berthou et al. (2024)。

## 四、一般均衡扩展（GTAP/CGE，可选深化）

若要评估"关税对三国**大豆产业**（产量、价格、福利）"的间接影响，用全球 CGE：
- 数据库：GTAP v11（2025 基准年），将"大豆"部门单独剥离（参考 Aguiar et al. 2021 的 HS 级细化流程）。
- 关税作为**税收楔子**进入模型（Cambridge CGE 教材 *Taxes in the GTAP Model*）：在 US→CN 大豆边加关税冲击，求解新均衡的产出、出口价、实际福利。
- 软件：GEMPACK / RunGTAP。
- 优点：捕捉汇率、国内价格、其他部门联动；缺点：参数多、对数据库依赖强，适合作为"敏感性/稳健性"补充而非主模型。

## 五、2018 自然实验校准与验证

把 **2018 年中美贸易战**（中国对美大豆加征 25% 关税）当作历史反事实：
- 用**事件研究 / 合成控制法**（参考 Brault et al. 2025）估计实际美豆对华出口下降幅度、巴西填补幅度。
- 将 2018 年的关税冲击代入核心模型，比较"模型预测值 vs 实际值"，校验 \(\sigma,\varepsilon,\eta\) 是否合理；偏差大的参数回溯重估。
- 这一步既满足题目"分析现状/历史"，又给模型提供经验可信度。

## 六、敏感性分析与稳健性

- 对 \(\sigma,\eta,\varepsilon_i\) 做 ±20%~50% 扰动，观察三国出口量/额分布的变动区间。
- 分情景：仅美国加税 / 中国对美反制 / 巴阿产能约束（供给弹性上限）三种情景对比。
- 报告基线与调整后（2025→调整后）的"出口量、出口额、份额"三联表。

### 一句话总览
**核心**：用 Armington CES 把"中国大豆总进口需求"拆成美/巴/阿三来源，关税楔子抬升美豆价格 → 份额向巴阿转移，联立进口需求弹性与各国出口供给弹性求解新的出口量/额分布；**校准**靠引力模型回估弹性；**验证**靠 2018 贸易战自然实验；**深化**用 GTAP/CGE 捕捉产业一般均衡效应。
